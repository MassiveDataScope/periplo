## How to sign

You sign once, in your first pull request:

1. Open a pull request. A bot comments if the CLA has not been signed yet by every author.
2. Read this document.
3. Reply to the pull request with this comment, on a line of its own:

   ```text
   I have read the CLA Document and I hereby sign the CLA
   ```

4. The check re-runs and turns green. Comment `recheck` if it does not.

Every author and co-author of the commits in the pull request must sign. Signatures are
recorded in this repository, together with your GitHub login and the pull request where you
signed.
